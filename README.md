# Student Grade Calculator

A beginner C++ project that calculates a student's total marks, average, and result.

## Features

- Accepts a student's name
- Accepts three marks
- Calculates the total marks
- Calculates the average
- Displays the student's result

## Concepts Practiced

- Variables
- Functions
- For loops
- If / else statements
- User input and output
- Basic arithmetic

## Technologies

- C++
- CLion

## What I Learned

This is one of my first C++ projects. I practiced using loops, functions, variables, and conditional statements to build a simple grade calculator.
